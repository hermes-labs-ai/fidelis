# Fidelis Memory 0.1.0 — local-first memory across five agent clients

Fidelis 0.1.0 establishes the first minor product contract for retrieving
original passages from a local memory store through an AI agent.

## Who it is for

The supported path is a developer on macOS or Ubuntu using Codex, Claude Code,
GitHub Copilot CLI, Gemini CLI, OpenClaw, or a local application integration.
Read the [user-fit matrix](../user-fit.md) before installing; it also names the
team, Windows, hosted-service, and authorization needs this release does not
claim to solve.

## Install or upgrade

```bash
python3 -m pip install "fidelis-memory==0.1.0"
```

Gemini CLI can install the tagged repository as a native extension after the
local prerequisites are running:

```bash
gemini extensions install https://github.com/hermes-labs-ai/fidelis
```

The PyPI distribution is `fidelis-memory`; the import and CLI are `fidelis`.

## What changed

- The supported Codex, Claude Code, GitHub Copilot CLI, Gemini CLI, and OpenClaw
  integration paths are now presented as one versioned product contract.
- All package, Python, registry, extension, citation, metadata, and current
  install surfaces carry `0.1.0`.
- The user-fit matrix makes supported users, prerequisites, and non-fits
  explicit before installation.
- Release mechanics and 0.x version policy are public and reproducible.
- The project roadmap is separated from shipped behavior by outcome gates.

## Acceptance evidence
